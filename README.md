# Generative AI Laboratory

Practicals executed on GitHub Actions, so that models run on hosted compute and every execution is documented
(workflow file, run logs, uploaded artifacts).

| Practical | Topic | Workflow |
|---|---|---|
| 4 | Multimodal application (VLM + text-to-image) and a RAG pipeline | [`practical-04.yml`](.github/workflows/practical-04.yml) |

Run a practical from the **Actions** tab (*Run workflow*) or with `gh workflow run practical-04.yml`.
Results are uploaded as artifacts of the run.
